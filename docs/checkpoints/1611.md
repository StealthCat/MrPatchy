# #1611: Monit control-file program contract, reconciled with #1373

Roadmap F (startup and scheduled-task awareness), Monit slice.

## 2026-11-26: native evidence and NUL-byte gap on the delivered #1373 contract

- **Reconciliation:** #1373 already delivered `app/monit_programs.py` (`evaluate(payload)`). #1611 and draft #1612 repeated that slice, and #1612 replaced the delivered module, its API, captured-include resolution and case-insensitive lexing ([review](https://github.com/StealthCat/MrPatchy/pull/1612#issuecomment-7204094150)). This increment keeps the #1373 module and API unchanged. It supersedes #1612.
- **Delivered:**
  - #1612's native monit 5.33.0 cases (Ubuntu 24.04 `1:5.33.0-2build2`, recorded by the #1612 session from `monit -v -t` and from an `-I` exec argv/uid trace) now run against `evaluate()` as regression tests. Main matches every native argv, uid, timeout and service result.
  - The native escape rewrite (`'  g\tq  '` becomes `g<TAB>q`) is not modelled. A test now pins it as the blocking gap `escape_sequence`.
  - New blocking gap `nul_byte`: a file containing NUL is not parsed. Before this change, `start "/bin/a<NUL>b"` was reported as complete with argv `/bin/a\x00b`, but monit copies words as C strings and would run `/bin/a`. The gap applies to included files as well.
- **Validation:** `tests/test_monit_programs.py` passes 57 tests. Reverting the NUL check fails 3 of them. The startup/monit test selection passes 447 tests. `ruff --select F` is clean, and `check_version --allow-unversioned` passes against main `c5bc4107`.
- **Not re-verified natively in this run:** the sandbox refused to execute the extracted monit binary, so the native values above are the ones #1612 recorded. #1612 also claimed that keywords are case-sensitive. That claim has no native evidence, so the conservative case-insensitive lexing from #1373 is kept.
- **Remaining for roadmap F:** built-in collection of the Monit control files and includes, a startup-catalog entry, and UI display.
