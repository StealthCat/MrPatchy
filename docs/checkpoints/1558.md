# Roadmap A checkpoint #1558 — fleet triage queue snapshot

## Scope

The administrator fleet triage breakdown reads the limited backlog, server names,
saved occupancy limits, and active leases in a single statement. The existing
model and key signature reads remain separate. The occupancy read counts every
unexpired lease on each displayed server, including investigations whose subject
left the pending list. SQLite and MySQL use the existing lease host index for this lookup.
The existing ordering, exact server total, pause and
retry classifications, and saved-policy fallback behavior remain in use.

This read-only change keeps the existing response fields and authorization.
It sends no provider requests and does not modify leases, budgets or scheduling.

## Acceptance and next milestone

The SQL statement-count regression failed on v1.102.1 with six reads. The target
is three reads including the two model/key signature reads. The existing
breakdown tests cover role isolation, truncation and empty pages, admission
occupancy after an approval, expired leases and malformed policies.

This checkpoint covers the dashboard read. Equivalent-capability production
throughput and the remaining parallel triage acceptance stay open.
