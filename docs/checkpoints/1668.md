# Keep hosted Ubuntu CI independent of the unused Microsoft APT feed

The Ubuntu runner's Microsoft prod feed returned HTTP 403 on all three
browser dependency installation attempts in integration PR #1665.
An earlier native RPM job in #1659 hit the same feed before running tests.
The affected jobs install their packages from Ubuntu's signed repositories.

The hosted-runner APT setup now comments out the exact Ubuntu 24.04 prod
entry in the Microsoft package's dedicated `microsoft-prod.list`. This
keeps the original entry and key reference visible and leaves other
sources, package signature checks, and failed-refresh handling in place.
It does not touch runtime, container fixture, or installer APT setup.

The regression fixture fails on main `5a77984b4268fb29f3496779ffac103b17e2cdf9`
because the Microsoft entry is still active. It also checks the signed
entry that ships in the official package, nearby URL variants, an unrelated
source file, and idempotence. The hosted browser, SQLite, MySQL, and RPM
checks provide native-runner validation.
