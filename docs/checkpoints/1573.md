# Read both legacy triage status counters in one snapshot

[#1573](https://github.com/StealthCat/MrPatchy/issues/1573) is a Roadmap A status-reporting increment. The legacy triage allowance shown in Settings and Investigations uses one statement to read both rolling-window counts and their reopening times. This removes one database round trip per legacy triage allowance read. The greater count, the wait for both counters to clear, exact-cutoff handling and zero-limit behavior are preserved.

The focused regression records two statements on v1.107.0 and expects one after the change. Existing cases also exercise independent counter exhaustion, scoring and advisory plan status. Admission rules and the API payload stay the same.
