# Checkpoint: collectd exec-plugin contract (#1551)

Roadmap F (startup and scheduled-task awareness), issue
[#1551](https://github.com/StealthCat/MrPatchy/issues/1551).

## 2026-11-26 — increment 1: pure contract

**Delivered** (branch `claude/vibrant-tesla-gupwnq`): `app/collectd_exec.py`, a pure contract
that takes captured `collectd.conf` text, captured `Include` targets (files and directory
listings) and captured `/etc/passwd` and `/etc/group` text, and reports each program
collectd 5.12.0's `exec` plugin starts:

- `Exec` programs (started at every read interval while not running) and `NotificationExec`
  programs (started per notification), with the source file and line;
- argv as the plugin builds it: basename argv[0], `%lf` numbers (`0755` is 755 because
  `strtod` reads it), lower-case-only booleans, and `PATH` search when the program has no `/`;
- the account: `getpwnam` uid and primary gid, the configured group as effective and
  supplementary gid, refusal of unknown users and of every uid 0 account, and the logged but
  ignored unknown group. A configured `root` group gives the program gid 0, and such
  programs are listed in `root_group_programs`;
- liboconfig scanning and parsing (longest-match tokens, echoed stray bytes, continuation
  lines, multi-line quoted strings, mandatory final newline, case-sensitive block close);
- `Include` expansion (top level only, `wordexp(WRDE_NOCMD)`, `strcmp`-sorted directories,
  basename `Filter`, depth 8) and which failures skip a drop-in versus reject the whole
  configuration;
- dispatch order: a `<Plugin exec>` block before `LoadPlugin exec` is ignored unless
  `AutoLoadPlugin` was set true earlier.

Unobserved files or listings, unsupported `wordexp` input (variables, quotes, `~`,
whitespace, relative paths, globs above the last component), a relocated `PluginDir`,
missing account databases and a non-root daemon are blocking gaps; a result with any gap is
not `complete`. `origin` is `not_assessed` and `authorizes_response` is always false.

**Validation:** 18 tests in `tests/test_collectd_exec.py`. Nine replay native runs of Ubuntu
24.04 `collectd-core 5.12.0-17.1build2` (`collectd -f -C` as root, traced with
`strace -f -e trace=execve,setgroups,setgid,setuid`): argv formatting and account handling
(`setgroups(2, [65534, 1])`, `setgroups(1, [65534])` for an unknown group,
`setgroups(2, [1, 0])` for `daemon:root`, the root refusal, the unknown user), the missing
final newline, the unquoted path, the case-mismatched block close, a block before
`LoadPlugin` with echoed bytes and a multi-line string, `AutoLoadPlugin` with an `Include`
inside the block, directory/glob/missing includes with a skipped broken drop-in, a direct
include not matching its `Filter`, and a direct include that fails to parse. The depth limit
(`l7.conf` not included), the `wordexp` failure on `;`, the empty configuration and an
unmatched glob were also checked natively.

**Compatibility:** new files only. No schema, route, UI, auth, scheduling, agent or
response-authorization change.

**Remaining under #1551:** agent collection of `collectd.conf`, its includes and listings,
startup catalog and provenance integration, UI, AI classification of the reported programs,
and the python/perl plugin module loading (`Import`, `LoadPlugin` of Perl modules), which
runs code inside the root daemon and needs its own slice.
