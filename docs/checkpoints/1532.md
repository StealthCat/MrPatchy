# Checkpoint: CUPS backend contract (#1532)

Roadmap F (startup and scheduled-task awareness), issue #1532, increment 1.

## 2026-11-25 — increment 1: pure contract

**Delivered** (draft PR on branch `claude/vibrant-tesla-okn2by`):

- `app/cups_backends.py` reports, for each `printers.conf` queue, the backend cupsd runs
  (`<ServerBin>/backend/<scheme>`), its argv[0] (the `DeviceURI` without `user:password@`),
  whether `_cupsFileCheck` refuses it, and the account it runs as: root when the backend has
  no world-execute bit, otherwise `User`/`Group` from `cups-files.conf`.
- `program_sha256` fingerprints the programs from credential-free fields only; raw `printers.conf` text (which can hold `DeviceURI` passwords) and account databases are never hashed (CodeQL `py/weak-sensitive-data-hashing` on `637b315`).
- Rules are ported from upstream CUPS 2.4.7 (`cupsFileGets`, `cupsFileGetConf`,
  `cupsdLoadAllPrinters`, `cupsdSetDeviceURI`, `cupsdContinueJob`, `cupsdStartProcess`,
  `_cupsFileCheck`, `read_cups_files_conf`). The module performs no I/O, reports
  `origin: not_assessed` and never authorizes a response action.
- Blocking gaps: unobserved file metadata, over-long or NUL-containing lines, duplicate or
  unterminated queues, unmappable schemes, refused or unknown `User`/`Group`, missing
  `ServerBin` and `ServerRoot` relocation.

**Validation:**

- `tests/test_cups_backends.py` (21 tests). One replays a native run of Ubuntu 24.04
  `cups-daemon 2.4.7-1.2ubuntu7.14` (`cupsd -f` as root, default `cups-files.conf`): backends
  with modes 0700 and 0744 ran as uid 0 gid 7; 0755 and 0705 ran as `lp` (7/7); 0775 was
  refused for insecure permissions; a missing backend stopped its queue; a compiled backend
  recorded argv[0] `argvprobe://printer.example:631/ipp/print?x=1` for a URI with credentials.
- Mutation checks: dropping the world-execute test fails 6 tests; dropping `\#` unescaping
  fails 2.

**Remains:**

- Collection of `printers.conf`, `cups-files.conf` and backend `stat()` metadata, startup
  inventory wiring, provenance and AI classification.
- Filters, notifiers and `cups-browsed` (which never run programs as root through this path),
  and `cupsd -c`/`-s` relocation, are out of scope.
- The native comparison is one run of one configuration; the Ubuntu build carries downstream
  patches (for example `PeerCred`) that this contract does not interpret.
