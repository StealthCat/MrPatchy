# Checkpoint: promoted startup scope keeps saved-path traversal depth (#1645)

Bug fix, P3. Issue [#1645](https://github.com/StealthCat/MrPatchy/issues/1645). Raised by the Codex review
of #1642/#1643.

## 2026-11-27 — fix

**Cause.** A saved custom path inside a promoted built-in directory (`PROMOTED_PERSISTENCE_ROOTS`) was
skipped, and only the built-in walk from the promoted root covered it. That walk applies `SCAN_MAX_DEPTH`
from the root, while the saved path used to start its own walk at depth 0. Files the saved path used to
reach were dropped behind a depth gap.

**Fix** (`target/agent.py`). The built-in walk of each root receives the saved promoted paths under it as
anchors. It always descends towards an anchor and restarts the depth budget at an anchor directory.
Coverage of each saved path matches its earlier own-root walk. Every entry is still listed once, and
directories that are neither anchors nor on the way to one keep the built-in limit and its disclosed gap.
Security scanning and other `scan_entries()` callers are unchanged.

**Validation.** `tests/test_promoted_scope_depth.py` (7 cases, inert temporary trees) fails 3 cases on
main `2a3f656` and passes with the fix. 49 startup, scope, persistence and agent test files (975 passed,
40 skipped) pass.

**Compatibility.** Agent-side only. No schema, route, UI, auth, scheduling or response-authorization
change. The ClamAV roots in #1643/#1644 use the same tuple, so they are covered once that merges.

## 2026-11-27 — review follow-up

**Finding.** An independent review of `79f4649` showed that once the walk passed `SCAN_MAX_DEPTH` only to
reach a saved path, it yielded every non-directory entry in that directory. An unsaved regular-file or
symlink sibling was inventoried with no gap.

**Fix.** Past the limit, `scan_entries()` follows only saved paths and their ancestors. It records one
`Directory depth limit reached` gap for each directory where it skipped anything else.

**Validation.** Two new cases (file and symlink siblings beside a deep saved file, and files beside a deep
saved directory) fail on `79f4649` and pass with the fix. The earlier sibling-directory case now expects
the gap on the sibling's parent. 9/9 depth cases pass. 746 startup, scope, persistence and agent tests
pass (40 skipped). Current main `5d9d087` (v1.120.0) is merged in.
