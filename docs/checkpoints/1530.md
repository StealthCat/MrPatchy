# Checkpoint: rsnapshot command contract (#1530)

Roadmap F (startup and scheduled-task awareness), issue
[#1530](https://github.com/StealthCat/MrPatchy/issues/1530).

## 2026-11-25 — increment 1: pure contract

**Delivered** (branch `claude/magical-goodall-yer5qx`): `app/rsnapshot_commands.py`, a pure
contract that takes file records for `/etc/rsnapshot.conf` and its `include_conf` files and
reports which programs rsnapshot 1.4.5 runs as the invoking user (root from the packaged
`/etc/cron.d/rsnapshot`):

- `cmd_preexec`/`cmd_postexec` (last valid assignment wins; extra tab fields are silently
  dropped; run from `$HOME`; a non-zero exit aborts rsnapshot);
- `backup_script` (run from `<snapshot_root>/tmp/`; failure rolls the destination back) and
  `backup_exec` (path never checked; `required` failure aborts);
- backtick `include_conf` commands, which run while the configuration is parsed, at every
  invocation including `configtest`, even when the configuration is later rejected;
- program paths (`cmd_rsync`, `cmd_ssh`, `cmd_cp`, `cmd_rm`, `cmd_logger`, `cmd_du`,
  `cmd_rsnapshot_diff`, `linux_lvm_cmd_*`) with their absent-key defaults;
- Perl's one-string `system()` shell-versus-`execvp` decision and argv for each command.

Configuration errors (spaces instead of tabs, relative hooks, unknown directives, include
cycles, missing includes, ordering rules for `snapshot_root` and `cmd_ssh`) are reported, and a
rejected configuration marks backup-time commands `runs_only_if_config_accepted`. Unobserved or
unknown files, NUL bytes, over-limit input, include depth and backtick-include output are named
coverage gaps; a result with any gap is not `complete`.

**Validation:** 21 tests in `tests/test_rsnapshot_commands.py`. Ten reproduce native runs of
rsnapshot 1.4.5-2 on Ubuntu 24.04 (perl 5.38.2, rsync 3.2.7) traced with
`strace -f -e trace=execve`: hook order and working directories, the dropped tab field, shell
selection, last-wins, continuation joining (including `#`-led continuations), required versus
optional `backup_exec` failure, backtick include running under `configtest` with a rejected
configuration, the self-include abort, and the final-`0` parse stop.

**Compatibility:** new files only. No schema, route, UI, auth, scheduling, agent or
response-authorization change.

**Remaining under #1530:** agent collection of the configuration and includes, startup catalog
and provenance integration, linkage to the cron entry that invokes rsnapshot (and alternate
`-c` files), UI, and AI classification of the reported commands.
