# Checkpoint: patch calendar weekend column order (#1540)

## 2026-11-26 — delivery

**Outcome:** the Patch calendar month view now shows its columns as **Sat · Mon · Tue · Wed · Thu · Fri · Sun**. The user asked for this non-chronological order so that the two weekend days sit at opposite edges.

**How it works:** the change is in `app/static/schedules.js`.

- The month range is still aligned to Monday, and each row is still one Monday–Sunday week. The loop collects a week's seven cells and emits them in the order `[5,0,1,2,3,4,6]`. The header uses the same permutation.
- A day's Saturday therefore sits at the left of the row for its own week, before that week's Monday. The day does not move into the previous week.
- Each cell keeps its real date, `data-day`, `today`/`outside` classes, event list and hourly-view link. Cells now also carry `data-weekday`.
- The day button's aria-label names the weekday, for example "Hourly schedule for Saturday 2026-02-28". The "+N more" link's label does too. Screen-reader and keyboard users can therefore tell that Tab moves from Saturday to Monday, because DOM order matches the visual order.
- The following are unchanged: the server `/schedules/calendar` range, timezone handling, schedule execution, the hourly view, the schedule form's day-of-week checkboxes and the maintenance-window lists.

**Validation:** `tests/ui_schedules.cjs`, which is part of `npm run test:ui`, now routes a February 2026 calendar with events on Saturday 2026-02-28 and Sunday 2026-03-01. Sunday 2026-03-01 falls outside the month. At 390 px and at 1440 px the test asserts:

- the header order;
- the first and last row date order;
- that each event appears in its own day's cell;
- the outside-month class;
- the aria-label;
- the left/right geometry within one row;
- that there is no horizontal scroll;
- Tab order from Saturday to Monday.

It then opens Saturday's hourly view with the keyboard and steps to Sunday with Next. It switches back to month view for March 2026 and confirms the rollover row (Sat 02-28, Mon 02-23 … Sun 03-01), then uses Previous.

**Remaining:** none for the stated acceptance criteria.
