# Update-scoring reply package reads (#1710)

The worker rechecks a provider reply against freshly loaded package evidence
before saving scores. The package read now shares the evidence projection used
at admission and fetches eight columns instead of twelve. Repository origin
text, repository priority, host ID and queue age are unnecessary for this
check. The worker still loads the current host inventory separately and uses
it to recalculate the exact assessment identity.

The reply-path regression captures the package and host SQL reads. On
v1.136.0 at `c31f5e4b84d96c3eb3021de0d99054f09a774041`, it detected the unused
repository origin column. It also checks that an unrelated repository-origin
change preserves a valid score, while changed or removed evidence supersedes
the original assessment.

There is no schema or provider request change. The regression measures the
selected columns and query count. Runtime throughput and database transport
bytes were outside this check.
