### Squid helper-program contract — worker checkpoint #1519 (roadmap F, increment 1)

Squid starts administrator-configured helper programs for URL rewriting, Store-ID mapping, authentication and external ACL lookups. A changed `squid.conf` line or include file can make it run a new program for proxied requests. When squid starts as root, these helpers run as `cache_effective_user`.

- **Increment 1 (draft):** the pure `app/squid_helpers.py` reports each configured `url_rewrite_program`, `store_id_program`, `auth_param <scheme> program` and `external_acl_type` helper. Each entry gives the executable, whether PATH resolves it, its argv, its source lines and, for external ACLs, the options and `%` format tokens. The run-as account comes from the last `cache_effective_user`/`cache_effective_group`, or the contract says the compiled-in default applies.
- **Semantics:** Squid 6.10 `cache_cf.cc` (`parseOneConfigFile`, `parseManyConfigFiles`, `ProcessMacros`, `FindStatement`, `EvalBoolExpr`, `parse_line`, `parse_wordlist`, `parse_authparam`, `parse_onoff`), `ConfigParser.cc` (`TokenParse`, `UnQuote`, `NextToken`, `NextQuotedToken`), `external_acl.cc` `parse_externalAclHelper`, `auth/SchemeConfig.cc`, `helper.cc` `helperOpenServers`/`helperStatefulOpenServers`, `ipc.cc` and `tools.cc` `leave_suid`:
  - physical lines are cut at the first CR and stripped of leading white space. `#` lines and empty lines are skipped, even inside a continuation. A trailing `\` continues the line only when it is the very last character;
  - `${service_name}`, `${process_name}` and `${process_number}` are replaced from an explicit process context;
  - `if`/`else`/`endif` are per file, and only the innermost `if` state gates a line, so a true `if` nested inside a false one still applies;
  - `include` takes whitespace-separated glob patterns. The collector supplies the matches in glob order, and a pattern with no match is fatal. Includes nest at most 16 deep;
  - directive names are case-sensitive. Wordlists always recognise `"`/`'` quoting with `\r`/`\n`/`\t` escapes, and a token that starts with `#` ends the list;
  - `configuration_includes_quoted_values on` quotes every value and enables the strict check on unquoted tokens. `parameters(...)` (any prefix of the word) reads a file;
  - repeated `url_rewrite_program`/`redirect_program` and `store_id_program`/`storeurl_rewrite_program` lines append to one command line. `auth_param <scheme> program` replaces that scheme's command, and only `basic`, `digest`, `negotiate` and `ntlm` are accepted;
  - argv[0] is `(basename)`, with at most 64 entries in all, and execvp runs the executable.
- **Fail closed:** blocking gaps cover:
  - runtime macros without a process context and `parameters()` files;
  - malformed quoting, unknown cfg functions and strict-mode token errors;
  - unknown auth schemes, empty auth programs and malformed `external_acl_type` lines;
  - unobserved, unmatched or quoted includes, and unbalanced or unevaluable `if` blocks, including `if` integers outside the 32-bit C `long` range (strtol saturates at a width that is not observed; digit counts are bounded before conversion);
  - NUL bytes, lines that fgets would split (8 KiB, measured in UTF-8 bytes with `surrogateescape` for captured undecodable bytes; an unencodable line is its own gap), and over-limit input;
  - helper directives outside this slice (`sslcrtd_program`, `sslcrtvalidator_program`, `logfile_daemon`, `unlinkd_program`, `diskd_program`, `pinger_program`, `sslpassword_program`, `cache_dns_program`).

  `complete` stays false whenever any of these is present, and no result is a safety verdict.
- **Validation:** `tests/test_squid_helpers.py` (26 tests, two of them regression tests for the review findings on `83bd65a`) uses vectors derived from the source. One of them is a native run: Ubuntu's squid 6.14 started as root with argv-recording helpers. Its four helpers started as uid `proxy` with argv identical to the contract's. That run covered the continuation across a comment line, alias appending, quoting and `#`, the nested-`if` quirk, auth last-wins and CR truncation. Between the SQUID_6_10 and SQUID_6_14 tags, `cache_cf.cc`, `ConfigParser.cc`, `external_acl.cc`, `auth/SchemeConfig.cc`, `helper.cc`, `ipc.cc` and `String.cc` differ only in their copyright line.
- **Remaining:** the compiled-default helpers that run without a config line (unlinkd, pinger, logfile daemon) and the SSL helper directives; `strwordtok` include quoting; broader native differential testing; collection of `squid.conf` and its includes; startup-inventory wiring, provenance and AI classification.
