# Checkpoint: Samba smb.conf command contract (#1580)

Roadmap F (startup and scheduled-task awareness), issue
[#1580](https://github.com/StealthCat/MrPatchy/issues/1580).

## 2026-11-26 — increment 1: pure contract

**Delivered** (branch `claude/magical-goodall-uf89to`): `app/samba_commands.py`, a pure
contract that takes captured `smb.conf` text and captured `include =` targets. It reports
each configured command with its parameter, share (or `None` for global), `[homes]`/`[printers]`
template, command string, account, trigger, source file and line, share availability and
whether a failing `root preexec`/`preexec` refuses the connection:

- share commands: `root preexec`/`root postexec` as root, `preexec` (synonym `exec`) and
  `postexec` as the connecting user, with `root preexec close`/`preexec close`;
- global commands (user/group/machine scripts, share and printer management, shutdown,
  quota, `panic action`, `passwd program`, `username map script`, `check password script`,
  `message command`, `wins hook`, `log nt token command`). The account is `root` only where
  the Samba 4.19 parameter documentation says so, `guest` for `message command`, and
  `not_assessed` otherwise;
- `lib/util/tini.c` line handling (comments, backslash continuation, whitespace-run
  collapse, one-character trim) and `loadparm.c` section handling (`[global]`/`[globals]`
  compared like `strwicmp`, shares snapshot the `[global]` defaults when first created,
  reopened shares, ignored global-only parameters in shares, textual includes, skipped
  missing includes, the 100-deep include limit, and whole-file rejection for a missing `]`,
  an empty name or an invalid tracked boolean).

Unobserved configuration or includes, `%`-substituted, relative or `registry` includes,
`config file`, `config backend = registry`, `copy =`, NUL bytes, invalid UTF-8 and
over-limit input are blocking gaps; a result with any gap is not `complete`. Printing,
`dfree`, `magic script` and AD DC command parameters are listed in
`configured_not_evaluated` when set. `origin` is `not_assessed` and
`authorizes_response` is always false.

**Validation:** 21 tests in `tests/test_samba_commands.py`, replaying Ubuntu 24.04
`samba 2:4.19.5` `testparm -s -v` results, plus a live `testparm` differential that runs
when Samba is installed. A local differential over 44 fixtures (including 40 generated
ones) matched `testparm` on every share/parameter and on whole-file rejection. A native
`smbd -F` run with `smbclient` guest connections showed an inherited global `root preexec`
and a share `root postexec` writing uid 0, `preexec` writing the guest uid 65534, and an
`available = no` share refusing the tree connect without running its command.

**Compatibility:** new files only. No schema, route, UI, auth, scheduling, agent or
response-authorization change.

**Remaining under #1580:** agent collection of `/etc/samba/smb.conf` and its includes,
`%` macro expansion, `copy =` evaluation, printing/`dfree`/`magic script` and AD DC
commands, the `smbd`/`nmbd` service command line (`-s`/`--configfile`), startup
catalog/provenance integration, UI and AI classification.
