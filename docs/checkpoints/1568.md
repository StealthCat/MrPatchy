# Reuse selected server identities in update scoring

[#1568](https://github.com/StealthCat/MrPatchy/issues/1568) is a Roadmap A scoring increment. Update scoring carries the selected server IDs forward from batch admission, saving one database read per nonempty batch. The same IDs feed the current policy check, lifecycle guard and durable AI run membership. Provider evidence is unchanged.

The focused regression builds three packages across two servers. On v1.106.0 it records a redundant distinct server query after batch selection. It also exercises provider scope, persisted server membership and result completion. Broader parallelism and distributed admission acceptance remain open.
