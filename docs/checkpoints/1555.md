### HAProxy program-section contract — worker checkpoint #1555 (roadmap F, increment 1)

In master-worker mode (Ubuntu and Debian start HAProxy with `-Ws`, as root), the master process forks each `program` section's `command` itself. The global `user`/`group` settings drop privileges for workers only. A program without its own `user` therefore runs with the master's identity, which is root under the packaged unit. A changed `haproxy.cfg` or a file added to a configuration directory can start a new long-running root process.

- **Increment 1:** the pure `app/haproxy_programs.py` takes the captured config files in load order. For each `program` section it reports the id, the argv, whether execvp searches PATH, `user`/`group` as written, whether supplementary groups are dropped, `start-on-reload`, source locations and any `master-worker` line in the config.
- **Semantics:** these come from HAProxy 2.8.30. The relevant code is `cfgparse.c` `readcfgfile`, `tools.c` `parse_line` (ENV, DQUOTE, SQUOTE, BKSLASH, SHARP and WORD_EXPAND), `cfgcond.c` integer terms, and `mworker-prog.c` `cfg_parse_program`, `cfg_program_postparser` and `mworker_ext_launch_all`:
  - lines have no length limit. A NUL byte, or a last line without LF, is fatal. Leading `isspace` characters are skipped;
  - words split on unquoted white space, including `\v` and `\f`. `#` starts a comment even in the middle of a word. Backslash escapes are `\ `, `\\`, `\t`, `\n`, `\r`, `\#`, `\'` and `\"` outside single quotes, `\$` inside double quotes and `\xHH`; any other backslash stays literal. A line holds at most 64 words, and a trailing empty word is not counted;
  - `$VAR` expands only inside double quotes. `.LINE`, `.FILE` and `.SECTION` are computed from their source location, and the `${name-default}` and `${name[*]}` forms are supported for them;
  - `.if`/`.elif`/`.else`/`.endif` work as follows. Integer-constant conditions use `strtol` base 0, so octal and hex are accepted. A masked parent skips nested blocks. `.elif` after `.else`, a lone `.else`/`.endif` and an unterminated block are all fatal;
  - `no`/`default` shift the words. Only `option`, `log` and a few global flags accept them, so `no command` is fatal;
  - section state starts empty in every file;
  - a duplicate program id is fatal. The last `command` replaces earlier ones, and its argv stops at the first empty word. For `user` and `group` the first value wins, and a repeat only alerts. `option start-on-reload` is on by default, and `default option` leaves it unchanged.
- **Fail closed:** the following are blocking gaps:
  - environment variables;
  - `.if` conditions other than integer constants;
  - scope directives;
  - `external-check` and `option external-check` in proxy sections, which are deferred to increment 2;
  - tokenizer errors, unknown directives, `.alert`, unsupported modifiers and out-of-section lines;
  - malformed, duplicate or command-less programs;
  - over-limit input.

  `complete` is false whenever any of these is present. No result is a safety verdict.
- **Validation:** `tests/test_haproxy_programs.py` has 10 tests. The first is a native run: Ubuntu 24.04 haproxy 2.8.30-0ubuntu0.24.04.2 was started as root with `haproxy -W -f a.cfg -f b.cfg`, and each program recorded its argv and uid/gid. The four started programs matched the contract's argv[1:], uid and gid exactly. That run covered quoting and escapes, a mid-word `#`, unexpanded `$HOME`/`${.SECTION}` outside double quotes, `.LINE`/`.FILE`/`.SECTION`, first-wins `user`, argv truncation at `""`, `.if 0`/`.elif 1`/`.else`, last-wins `command`, a second file with `group` only (gid 65534, uid 0) and `no option start-on-reload`. Twelve rejected configurations were also checked against `haproxy -c` exit status 1.
- **Remaining:** per-backend `external-check command`/`path` health-check scripts (defaults inheritance, `option external-check`, `insecure-fork-wanted`, `global external-check`), Lua `lua-load` files, collection of `/etc/haproxy` and the unit's `-f` arguments, and startup-inventory wiring, provenance and AI classification.
