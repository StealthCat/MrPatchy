# Retry temporary APT index failures in CI

[#1578](https://github.com/StealthCat/MrPatchy/issues/1578) tracks package-index size mismatches that stopped the Ubuntu SSH enrollment fixture and an Ubuntu MySQL recovery job before their tests ran.

The native CI package steps and the SSH fixture share a refresh helper with three attempts and 5- and 10-second waits. APT treats every refresh error as a failed attempt. Repositories, signing configuration and package install commands are unchanged. Exhausted refresh attempts prevent package installation.

The focused test drives the actual recovery prerequisite with a simulated one-time or sustained mirror failure. The v1.109.0 command fails after one attempt. The worker retries temporary failures and preserves the final APT error on exhaustion. Hosted Ubuntu and Debian fixture validation is required before handoff.
